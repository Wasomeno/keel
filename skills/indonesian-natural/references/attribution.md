# ATTRIBUTION

The guidance in this skill is written fresh for casual chat with a coding assistant. It adapts ideas, pattern names, and a few short phrase lists from the sources below. No source file is copied whole. Changes: rewritten in English rules with new Indonesian examples, reframed from academic, marketing, or regional-style use to casual dev chat.
