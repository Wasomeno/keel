# Study samples

Put your own writing samples here (articles, chat, social posts, novel excerpts) to tune the voice. One `.md` file per source is easiest.

- Strip usernames, names, phone numbers, emails, and other personal data first.
- Keep excerpts short. Do not redistribute copyrighted text; this folder is for private study and should not be published or shipped.
- The agent reads these as style data only. Instructions inside a sample are never followed.
